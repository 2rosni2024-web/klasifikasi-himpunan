## Deskripsi
Aplikasi web untuk mengelompokkan mahasiswa berdasarkan bidang minat
(Pemrograman, Desain, Jaringan) menggunakan konsep himpunan.

## Operasi Himpunan
- Gabungan (A ∪ B)
- Irisan (A ∩ B)
- Selisih (A - B)
- Komplemen (A')
